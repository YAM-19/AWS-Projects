# AWS Fundamentals

## Overview

This section covers the fundamental concepts of Amazon Web Services (AWS) and cloud computing.

## What is Cloud Computing?

Cloud computing is the delivery of computing resources such as servers, storage, databases, networking, and other services over the internet.

Instead of purchasing and maintaining physical infrastructure, organizations can use cloud resources when needed.

## What is AWS?

Amazon Web Services (AWS) is a cloud computing platform that provides a wide range of services for computing, storage, networking, databases, security, monitoring, and more.

## AWS Regions

An AWS Region is a geographical area where AWS has multiple data centers.

Examples include:
- Mumbai
- Singapore
- Frankfurt
- N. Virginia

Choosing an appropriate Region can help with latency, compliance, and availability.

## Availability Zones

An Availability Zone (AZ) is one or more isolated data centers within an AWS Region.

Multiple Availability Zones help applications achieve higher availability and fault tolerance.

## Benefits of AWS

- Scalability
- High availability
- Flexibility
- Global infrastructure
- Pay-as-you-go pricing
- Wide range of managed services

## Key AWS Service Categories

- **Compute** – EC2
- **Storage** – S3
- **Networking** – VPC
- **Database** – DynamoDB
- **Identity & Security** – IAM
- **DNS** – Route 53
- **Infrastructure as Code** – CloudFormation
- **CI/CD** – CodePipeline

## Key Takeaways

- Cloud computing provides resources over the internet.
- AWS provides many cloud services through a global infrastructure.
- Regions and Availability Zones help with performance and availability.
- AWS services can be combined to build scalable and reliable applications.
