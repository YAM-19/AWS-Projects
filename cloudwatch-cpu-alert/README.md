# AWS CloudWatch – EC2 CPU Alert

## Overview

Amazon CloudWatch is an AWS monitoring and observability service used to monitor AWS resources, applications, and services.

In this project, I used Amazon CloudWatch to monitor an EC2 instance using the CPUUtilization metric and created a CloudWatch alarm to monitor CPU usage.

## Key Concepts

- **Metrics:** Numerical data collected from AWS resources.
- **CPUUtilization:** An EC2 metric that shows CPU usage.
- **Alarms:** Monitor metrics and trigger when a configured threshold is reached.
- **Dashboards:** Provide a visual view of resource performance.
- **Monitoring:** Helps identify performance and resource issues.

## Practical Implementation

I used AWS CloudWatch to monitor an EC2 instance and created a CPU utilization alarm. The alarm monitors CPU usage and changes its state when the configured threshold is reached.
