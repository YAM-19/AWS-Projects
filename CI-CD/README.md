# CI/CD and AWS CodeCommit

## Overview

Learned the basics of Continuous Integration (CI) and Continuous Delivery/Deployment (CD), and how AWS CodeCommit can be used as a source code repository in a CI/CD workflow.

## CI/CD

CI/CD automates the process of integrating, testing, and deploying application code.

### CI/CD Flow

Developer → Code Repository → Jenkins → Build → Test → Deployment

## AWS CodeCommit

AWS CodeCommit is a managed source control service used to store and manage source code repositories.

### CodeCommit in CI/CD

Developer → CodeCommit → Jenkins → Build/Test → Deployment

## Jenkins

Jenkins acts as an automation and orchestration tool in the CI/CD pipeline. It can monitor the source code repository and trigger pipeline activities when code changes are made.

## Key Concepts Learned

- Continuous Integration (CI)
- Continuous Delivery (CD)
- Version Control System (VCS)
- AWS CodeCommit
- Jenkins
- CI/CD Pipeline
- Build and Testing
- Application Deployment
